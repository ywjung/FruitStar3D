# 구현 상태

기준일: 2026-11-26 · 대상: macOS (Apple Silicon, Metal) · 버전 0.1.0

상태 표기: **완료**(구현하고 검증함) · **부분**(일부만 구현했거나 검증이 부족함) · **미구현**.
검증 방법과 결과는 `TEST_RESULT.md`, 남은 문제는 `ISSUE_LIST.md`에 있다.

## 요약

계획서의 10주 범위 중 1~8주차에 해당하는 기능을 한 번에 구현한 첫 개발 빌드다.
게임기 한 대(FRUIT CLASSIC)를 처음부터 끝까지 플레이할 수 있고, 도메인 로직은 자동 테스트로 검증했다.
반면 3D 모델(Blender/GLB), 음향의 청취 검증, 장시간 안정성 시험, 외부 배포용 서명·공증은 하지 않았다.
"실제 게임기 같은 외관"이라는 최우선 목표에 대해서는, 상자 위주의 절차 생성 모델이라 아직 시안 수준이다.

## 계획과 다르게 정한 것

- **Bevy 0.20.1 / Rust 1.100.0**: 설치되어 있던 Rust 1.88로는 최신 Bevy를 쓸 수 없어, 전역 기본 툴체인은
  그대로 두고 `rust-toolchain.toml`로 프로젝트 전용 툴체인을 고정했다.
- **체리 규칙**: 처음에는 "왼쪽 릴에 체리가 보이면 성립"으로 설계했으나, 그 규칙에서는 포도·리플레이가
  어떤 정지 순서에서도 반드시 성립한다는 보장을 만들 수 없음을 전수 검사로 확인했다.
  그래서 모든 역할을 "유효 라인에 같은 심볼 세 개"로 통일했다.
- **음향 파일 형식**: 모두 WAV다. 계획서가 .ogg로 적은 항목도 WAV이며 이름은 같다.
- **오디오 엔진**: Kira 대신 Bevy 내장 오디오를 썼다.
- **패키징**: `cargo-bundle` 대신 `scripts/package.sh`가 번들을 직접 만든다.
