# UI_DESIGN

화면 UI(`fruit-star-ui`)와 캐비닛에 달린 표시 장치(`fruit-star-machine`의 `display.rs`, `lamp.rs`)를 정리한다.
조작 방법은 [USER_GUIDE.md](USER_GUIDE.md)에 있다.

## 1. 화면

모든 화면은 시작할 때 한 번 만들어 숨겨 두고, `show_screens`가 상태에 따라 보이게 한다 (`ui/lib.rs`, `ui/screens.rs`).
화면 UI는 3D 장면 위에 얹힌다. 플레이 HUD의 표시 전용 노드는 `Pickable::IGNORE`를 사용해 뒤의 3D 부품을 클릭할 수 있다.

| 화면 (`Screen`) | 보이는 조건 | 내용 |
|---|---|---|
| `Loading` | `AppState::Loading` | 체리 간판과 불러오기 상태 |
| `Failed` | `AppState::Failed` | 제목, 실패 사유, 종료 버튼 |
| `Menu` | `AppState::MainMenu` | 왼쪽 인쇄 패널에서 모드 또는 기록 선택, 오른쪽에 회전하는 캐비닛 |
| `Hud` | `InGame`이고 일시정지 아님 | 위 왼쪽에 계기판, 아래에 조작표·시점·일시정지 버튼과 결과 메시지 |
| `Pause` | `InGame`이고 일시정지 | 어둡게 처리한 캐비닛 위에 음향·화면 설정판 |
| `Debug` | 디버그 단계 > 0 (개발 빌드 전용) | 오른쪽 위의 수치 패널 |

`Failed`로 가는 경우: 필수 리소스 파일이 없을 때, 이미지를 읽지 못했을 때, 픽셀 형식을 처리하지 못했을 때.

## 2. 메인 메뉴

메인 메뉴와 로딩 화면의 간판은 `fruit-star-assetgen`이 자체 글자 경로와 릴의 체리 그림을 조합해 생성한다.
클래식 시작 버튼은 적색, 나머지 모드는 크림색 패널에 배치한다. 메뉴 카메라는 캐비닛을 오른쪽에 두고, 플레이를 시작하면 선택한 모드의 시점으로 돌아온다.

| 항목 | 동작 |
|---|---|
| Classic 플레이 | `SessionCommand::Start { Classic, Play }` |
| Free Play | `Start { FreePlay, Play }` |
| Practice (연습) | `Start { Practice, Play }` |
| Mechanical View (내부 관찰) | `Start { FreePlay, Mechanical }` |
| Gallery (둘러보기) | `Start { FreePlay, Gallery }` |
| 언어 | 한국어 → 일본어 → 영어 순으로 전환 |
| 플레이 기록 | 모드 목록과 누적 기록표를 전환한다 |
| 기록표의 기록 초기화 | 한 번 누르면 확인 문구로 바뀌고, 4초 안에 다시 누르면 실행 |
| 종료 | 프로그램 종료 |
| 통계 (기록표) | 플레이 횟수, 투입 / 지급 합계, 보너스 BIG / REG 횟수, 플레이 시간, 달성 기록 개수. 저장소를 열지 못했으면 이번 실행에서만 유지된다는 문구 |
| 알림 (텍스트) | 최근 알림 한 줄 |

## 3. HUD

| 위치 | 표시와 조작 |
|---|---|
| 위 왼쪽 | 모드와 음소거 상태. 플레이할 때 크레딧·베팅·지급 수치를 세 칸에 표시한다. 연습 중에는 내부 추첨과 이월 보너스도 함께 보인다. |
| 아래 가운데 | 당첨 조합과 지급량, 보너스 잔여량, 메달 부족, 달성 알림을 해당할 때만 표시한다. |
| 아래 왼쪽 | 조작표 버튼으로 설정된 키 목록을 열고 닫는다. 갤러리에서는 시점·화면·음향 단축키와 회전·확대 방법을 안내한다. |
| 아래 오른쪽 | 시점 전환과 일시정지 버튼에 현재 키 배정도 표시한다. |

위 표는 키보드·마우스 화면이다. 휴대폰(터치) 화면은 3D 화면 위에 띄우지 않고, 화면 위아래 끝을 차지하는
두 막대로 나눈다.

| 위치 | 표시와 조작 |
|---|---|
| 상단 표시줄 | 안전 영역(카메라 섬)부터 화면 위 끝까지 채운다. 한 줄에 모드·음소거, 크레딧·베팅·지급, 시점·일시정지 버튼. 아래에 빨간 경계선 |
| 하단 조작판 | 화면 아래 끝까지 채운다. 메달·1 BET·MAX BET·START 한 줄과 정지 버튼 세 개 한 줄. 버튼은 모서리를 둥글게 하고 아랫면을 두껍게 칠해 누르면 들어가 보이게 했다. 위에 빨간 경계선 |
| 하단 조작판 바로 위 | 당첨·알림·메달 부족 안내와 연습 모드의 내부 추첨·이월. 메달 부족 안내에는 키 이름을 붙이지 않는다 |

두 막대가 실제로 덮는 높이(배치가 끝난 크기)를 `HudInsets`로 카메라에 알리고, 카메라는 시점 방향을 바꾸지 않고
화면을 위아래로 옮겨(`panned_transform`) 주시점이 두 막대 사이 빈 곳의 가운데에 오게 한다. 일시정지 화면에서는
막대가 숨지만 직전 값을 두어 장면이 움직이지 않는다. 세로 화면의 기본 플레이 시점은 주시점을 조금 올려
(`PORTRAIT_PLAY_TARGET`) 위쪽 계수기(GAMES·BIG·REG·TOTAL)부터 정지 버튼까지가 빈 곳에 들어온다.

크레딧·지급은 캐비닛 7세그먼트와 같은 `DisplayValues`를 읽는다. 베팅은 대기 중에 현재 걸린 수량을, 회전과 결과 표시 중에는 해당 판에 건 수량을 보여 준다.

알림 종류: 기록 초기화 완료, 기록 저장 실패, 달성 기록 7종(첫 지급, 첫 리플레이, 첫 BIG, 첫 REGULAR,
스타 세 개, 100게임, 1000게임).

## 4. 일시정지 · 설정 화면

HUD의 일시정지 버튼이나 기본 키 `P`, `Esc`로 연다. 가상 시간이 멈추므로 릴, 애니메이션, 물리가 함께 선다.

| 항목 | 조작 | 범위 | 적용 시점 |
|---|---|---|---|
| 계속하기 | 버튼 | | |
| 전체 음량 | − / + (10% 단위) | 0 ~ 100% | 즉시 |
| 효과음 | − / + | 0 ~ 100% | 즉시 (재생 중인 단발음 제외) |
| 배경음 | − / + | 0 ~ 100% | 즉시 |
| LED 밝기 | − / + | 0 ~ 150% | 즉시 |
| 점멸 줄이기 | 켬 / 끔 전환 | | 즉시 |
| 그래픽 품질 | LOW → MEDIUM → HIGH → ULTRA 순환 | | 재시작 후 |
| 언어 | 순환 | | 즉시 |
| 메뉴로 | 버튼 | | 세션을 닫고 메인 메뉴로 |

여기서 바꾼 값과 언어, 음소거 상태는 SQLite의 `user_settings`에 저장되고, 다음 실행 때 설정 파일 값 위에 덮어쓴다.
설정 화면은 일시정지 화면 안에만 있다. 메인 메뉴에서는 언어만 바꿀 수 있다.

## 5. 다국어 (`ui/i18n.rs`)

- 번역표는 `(키, [한국어, 일본어, 영어])`의 정적 배열이다. `tr(language, key)`로 조회하고, 없는 키는 키 문자열을
  그대로 돌려준다.
- 고정 문자열은 `Localized(키)` 컴포넌트, 상태에 따라 바뀌는 문자열은 `Dynamic` 열거형으로 표시한다.
  언어가 바뀌면 `localize` 시스템이 문자열과 글꼴을 한꺼번에 갈아 끼운다.
- 글꼴은 macOS 시스템 글꼴을 이름으로 찾는다 (Bevy의 `system_font_discovery` 기능).
  한국어 "Apple SD Gothic Neo", 일본어 "Hiragino Sans", 영어 "Helvetica Neue". 번들한 글꼴 파일은 없다.
- 기본 언어는 `config/application.toml`의 `game.language`(`ko`)이고, 화면에서 바꾸면 저장된다.
- 모든 키가 세 언어로 채워져 있는지와 UI가 쓰는 키가 표에 있는지를 `ui/tests/i18n.rs`가 검사한다.

번역되지 않는 것: 캐비닛의 라벨 텍스처(CREDIT, PAYOUT, COUNT, STAR CHANCE, MAX BET, START, STOP, INSERT MEDAL)는
영어 그림이다. 실행 불가 화면의 사유, 설정·저장소 경고, 로그는 한국어로만 나온다.

## 6. 캐비닛의 표시 장치

### 7세그먼트 표시기

릴 패널 아래쪽에 왼쪽부터 CREDIT, COUNT, PAYOUT 순으로 있다. 획 하나가 메시 하나이고 점등 여부에 따라 재질을 바꾼다.

| 표시기 | 자릿수 | 값 |
|---|---:|---|
| CREDIT | 4 | 보유 메달에서 아직 배출 연출이 끝나지 않은 지급분을 뺀 값 |
| COUNT | 3 | 보너스 중 남은 지급 가능 메달 수. 보너스가 아니면 꺼진다 |
| PAYOUT | 2 | 이번 게임에서 지금까지 배출된 메달 수. 레버를 당기면 0으로 돌아간다 |

앞자리 0은 끄고, 자릿수를 넘는 값은 최댓값(9999, 999, 99)으로 표시한다 (`display.rs`의 `segment_lit`).

### 램프

| 램프 | 동작 (`lamp.rs`의 `update_lamps`) |
|---|---|
| 외곽 LED 띠 (좌, 우, 상단) | 아래 연출 모드에 따른다 |
| STAR CHANCE | 켜지는 순간 0.6초 동안 번쩍인 뒤(점멸 줄이기에서는 한 번 밝아짐), 보너스를 맞출 때까지 하늘색으로 일정하게 켜져 있다. 그 밖에는 꺼짐. 실기의 보너스 고지 램프(GOGO 램프)에 해당한다 |
| 릴 조명 | 항상 켜져 있고, 당첨 연출 중에는 깜빡인다 |
| 정지 버튼 | 그 릴을 멈출 수 있을 때 밝게, 아니면 어둡게 |
| MAX BET / 1 BET 버튼 | 아직 걸지 않았으면 맥동, 일부만 걸렸으면 은은하게, 최대까지 걸렸으면 계속 켜짐, 그 밖에는 어둡게 |
| 유효 라인 등 (표시창 양옆, 라인마다 2개) | 베팅으로 유효해진 줄은 호박색, 당첨된 줄은 금색으로 깜빡인 뒤 켜진 채 유지 |
| 당첨 라인 막대 (표시창 위) | 당첨된 줄에만 나타나 다음 게임의 레버를 당길 때까지 남는다 |
| 배당표 (표시창 위) | 심볼 9종과 세 개가 늘어섰을 때의 배당. 항상 켜져 있다 |
| 데이터 카운터 (게임기 위) | GAMES(마지막 보너스 이후 게임 수), BIG, REG, TOTAL(총 게임 수). 게임기 앞에 앉은 뒤부터 센다 |
| 톱 램프 (데이터 카운터 위) | 보너스 중과 당첨 때 붉게 점멸, STAR CHANCE 램프가 켜져 있으면 푸르게 맥동 |
| 상태등 REPLAY / START / INSERT MEDAL (표시창 오른쪽) | 리플레이 대기 / 레버를 당길 수 있음 / 메달이 없어 투입 필요 |
| 상단 간판, 하단 장식 패널 | 백라이트. 당첨·보너스 중에 조금 더 밝다 |

| 연출 모드 (`LampMode`) | 조건 | LED 패턴 |
|---|---|---|
| `Attract` | 대기 | 금색 빛이 천천히 흐른다 |
| `Spin` | 회전 ~ 평가 | 따뜻한 흰색 빛이 빠르게 흐른다 |
| `Win` | 결과 표시 중이고 지급·리플레이·보너스 시작이 있을 때 | 금색 점멸 (5 Hz) |
| `Bonus` | 보너스 진행 중 | 무지개색 흐름. 시작 직후 2.5초는 강조 점멸 (6 Hz) |

좌우 띠는 아래에서 위로, 상단 띠는 가운데에서 바깥으로 흐른다.

## 7. 접근성 관련 설정

| 설정 | 효과 |
|---|---|
| LED 밝기 (0 ~ 150%) | LED, STAR CHANCE, 버튼 램프의 발광에 곱한다. 릴 조명과 패널 백라이트는 가독성을 위해 60% 아래로 내려가지 않는다 ([GRAPHICS_DESIGN.md](GRAPHICS_DESIGN.md) 2절) |
| 점멸 줄이기 | 켜짐/꺼짐이 반복되는 점멸을 1 Hz 이하의 얕은 밝기 변화(0.8 ~ 1.0)로 바꾸고, 흐르는 빛의 속도를 낮춘다. `machine/tests/logic.rs`의 `reduce_flashing_removes_hard_blinking`이 검사한다 |
| 음소거 (`M`) | 모든 소리를 끈다. HUD에 음소거 상태가 표시된다 |
| 입력 방식 | 게임기 조작은 키보드와 마우스·트랙패드 어느 쪽으로도 할 수 있다 |
| 조작 안내 | HUD의 조작표가 설정 파일에 배정한 키와 3D 조작법을 보여 준다 |

인터페이스 배율은 카메라의 논리 크기를 따른다. 작은 창에서는 메뉴 여백과 행 높이를 줄인다. 조작표를 펼치면 왼쪽 계기판을 잠시 접고, 하단의 닫기 버튼은 같은 자리에 둔다. 개별 글자 배율과 색각 보정 옵션은 향후 과제다. 화면 낭독기 호환성은 검증하지 않았다.

## 8. 디버그 표시 (개발 빌드 전용)

`F3`으로 단계를 0 → 1 → 2 → 0 순으로 바꾼다. 릴리스 빌드에서는 키 입력을 무시하고,
와이어프레임·충돌체 표시 플러그인도 등록하지 않는다.

| 단계 | 표시 |
|---|---|
| 1 | FPS, 프레임 시간, 프로세스 메모리, 전체 상태(`GameState`)와 게임 번호, 릴별 각도·각속도·상태, LED 밝기 평균과 최댓값 |
| 2 | 1에 더해 전체 와이어프레임과 Rapier 충돌 영역 |

## 9. 미구현 / 계획과의 차이

- 기종 선택 화면이 없다. 기종이 한 대뿐이라 메뉴에서 바로 시작한다.
- 독립된 설정 화면과 키 배정 화면이 없다. 키 배정, Bloom·그림자 등 그래픽 세부 옵션, 창 크기는 TOML로만 바꾼다.
- 플레이 기록표는 합계와 달성 개수를 표시한다. 개별 판이나 달성 항목의 목록은 구현하지 않았다.
- 전체 화면 전환은 `F` 키로만 한다. 메뉴 항목이 없고 상태를 저장하지 않는다.
- Practice 모드의 추첨 결과 지정 UI가 없다 ([GAME_DESIGN.md](GAME_DESIGN.md) 11절).
- Retina 화면에서의 가독성은 자동 검사가 없고 수동 확인 대상이다.
